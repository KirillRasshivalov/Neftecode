# Допущения проекта

Фиксируйте здесь всё, что жюри должно увидеть явно.

## Управляемые параметры

- Whitelist и диапазоны: `configs/tags_whitelist.yaml`.
- Пока стоят `PLACEHOLDER_*` — заменить по справочнику КИП и технологическим схемам.
- Диапазоны с `assumption: true` — модельные, не промышленные пределы.

## Качество

- Контрольный факт: ЛИМС → ПАК → виртуальный/расчётный.
- Сера товарного дизеля: ≤ 10 мг/кг (жёстко).
- Возраст анализа обязателен; пороги stale — в `constraints.yaml`.

## Надёжность / риск оборудования

- Прямой разметки может не быть; прокси-метрики описывать здесь после согласования с ML-2.

## Синхронизация

- Только по времени (`date`), не по номеру строки.
- Телеметрия: 10-минутный шаг.

## Train/test

- Только временной split; shuffle строк запрещён.
